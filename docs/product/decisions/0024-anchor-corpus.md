## Context

The tenancy-evidence closure left maintenance decisions on an explicitly
weaker evidentiary standard, and Aurelia's timing supervision had no dense
label source that wasn't on-policy biased. The owner proposed paying the
full counterfactual cost on a small host set as training wheels, then
generalised: fork at decision points, fork per action class, generate the
corpus with scheduled or random decision points — no working policy needed.

## The call

Adopt the anchor corpus as the fourth primary scaffold (ADR-0011; INV-39
amended three→four declared regimes). Label routing is
authority-partitioned through blinded views — the challenge cycle's key
fix: Aurelia receives only the marginalised commission-value slice
(topology preference is a signal it cannot legally express, INV-09);
per-action detail routes to Stage-1B validation, the Urborg/Momir
bootstrap corpus, and Ugin class statistics; the admission fork run to
tenure end calibrates the re-adaptation instrument. Honest-evidence
caveats are written into the design text (n counts seeds per INV-32,
path-conditional labels, bootstrap-scale tenures). Cost pre-accepted by
the owner for a few-dozen-seed corpus; the §22.11 model owns the numbers.

## Rationale

One corpus cost serves three consumers, and the challenge cycle
demonstrated the product discipline working as designed: the owner asked
to be challenged, the challenge found a real INV-09 leak, the owner's
clarification ("the old Tamiyo held both authorities; the principle
abstracts") resolved it into a stronger design than either starting point.

## Reversal trigger

As recorded in ADR-0011: if the measured corpus cost exceeds the declared
seed budget, shrink action set and decision sampling before seeds; if
calibration cannot exclude gross divergence, instruments do not loosen and
the pacing plan reopens by PDR — never by silently trusting the
uncalibrated instrument.
